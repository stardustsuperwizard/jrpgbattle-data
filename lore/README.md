# Lore

One file per champion: the public-domain sources it draws from, and the Mega Fighters telling of its story. Lore is kept apart from `data/` so the two can carry different licences: the plan is a Creative Commons licence for the data and the lore held back (jrpg-battle#248). Until then, both are unlicensed.

**Draw from the ancient sources, not later adaptations.** The Greek myths are public domain; modern films, games and comics about them are not, and their particular designs, names for things and stories stay theirs.
